# Pedra, Papel e Tesoura

Jogo simples de Pedra, Papel e Tesoura desenvolvido em JavaScript, rodando no navegador.

## Funcionalidades

* Jogar contra o computador
* Exibição do resultado de cada rodada
* Sistema de pontuação
* Encerramento automático ao atingir 5 pontos

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
